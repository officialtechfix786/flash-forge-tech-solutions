# Flash Forge Tech Solutions

A separate GitHub Pages website for mobile-device information, technician services and categorized software resources.

## Structure
- `index.html` — homepage and device search
- `downloads.html` — four separate download collections
- `assets/css/style.css` — responsive visual system
- `assets/js/database.js` — expandable starter device dataset
- `assets/js/app.js` — search, filters and device detail modal

## Important data policy
The current device list is a starter dataset, not a claim of complete A–Z coverage. Add models only after verifying model names, variants, service compatibility, image rights and prices. Unknown prices remain **Contact for Price**. Do not publish fabricated device images or unofficial download links.

## GitHub Pages
After the files are committed, enable Pages in **Settings → Pages → Deploy from a branch → main → /(root)**. The site will then publish at the repository's GitHub Pages URL.

## Supplied package
The fourth download collection links to the MediaFire package supplied by the site owner. It remains separate from PC, Android and iPhone tools.
